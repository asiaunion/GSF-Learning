# GSF-Learning: Adventure Map + SRS 시스템 통합 디자인

만 7세 아이의 몰입도를 극대화하는 **게이미피케이션(지도)**과 학습 효율을 위한 **스페이스트 리피티션(망각 곡선 복습)**을 결합한 확장 아키텍처 스펙입니다.

## 1. Core Concept (핵심 경험)

1. **학습 진도 (Adventure Map)**: 기존의 딱딱한 아코디언 리스트 대신, 게임의 '스테이지 맵'을 탐험하듯 다음 레슨을 열어가는 UI를 제공합니다.
2. **복습 루틴 (Today's Quest)**: 홈 화면 최상단에 "오늘의 복습 미션!" 버튼을 두어, 망각 곡선 알고리즘(SRS)이 '오늘 꼭 다시 봐야 할 카드'들을 자동으로 추려서 퀴즈/복습을 진행합니다.
3. **보상 (Daily Stamp & Stars)**: 레슨 완료나 복습 미션을 깨면 달력에 '출석 스탬프'가 찍히고, 별(⭐)을 획득해 아이의 시각적 성취감을 채워줍니다.

---

## 2. 콘텐츠 확장 로드맵 (Phase 1~5)

향후 일본어 학습 확장을 위한 맵(Map) 테마 구성입니다.

- **Phase 1: 히라가나 마을 (Hiragana Village)** - 기존 레슨 1~14
- **Phase 2: 가타카나 숲 (Katakana Forest)** - 기존 레슨 15~28
- **Phase 3: 단어의 바다 (Words Sea)** - 주제별 필수 단어 대규모 확충 (동물, 색깔, 음식, 탈것, 가족 등). (빠른 구축을 위해 초기에는 고품질 이모지 🍎, 🐶, 🚗를 이미지 대신 활용)
- **Phase 4: 마법 한자의 산 (Magic Kanji)** - 일본 초등학교 1학년 필수 한자 (80자)
- **Phase 5: 인사말 성 (Greetings Castle)** - 일상 생활 짧은 회화 문장

---

## 3. Data Flow & Architecture

데이터 모델이 대폭 확장되며, 기존 진도 배열(`completedLessons`)을 넘어 카드 단위의 메타데이터를 로컬(또는 향후 Firebase)에 저장합니다.

### 상태 스토어 (`localStorage` 기반 구조)
```json
{
  "profile": {
    "stars": 120,
    "currentStreak": 5,
    "lastActiveDate": "2026-06-27"
  },
  "mapProgress": {
    "unlockedLessonId": 16,
    "completedLessons": [1, 2, ..., 15]
  },
  "srsStats": {
    "card_hiragana_a": {
      "interval": 3, 
      "easeFactor": 2.5,
      "nextReviewDate": "2026-06-30"
    }
  },
  "dailyLogs": {
    "2026-06-27": {
      "cardsReviewed": 15,
      "lessonsCompleted": 1,
      "stampEarned": true
    }
  }
}
```

### 핵심 모듈 분리 (Vanilla JS)
- `MapRenderer`: SVG 또는 CSS Flex 기반의 꼬불꼬불한 노드 경로 렌더링. 잠금/해제 상태 시각화.
- `SRSEngine`: 학습 결과(어려움/보통/쉬움)를 받아 Anki의 SM-2 알고리즘 베이스로 `nextReviewDate`를 계산.
- `DailyLogUI`: 스탬프북 모달. `dailyLogs`를 읽어 이번 달 달력에 조셉(마스코트) 도장을 찍어줌.

## 4. UX / UI 시나리오

1. **홈 화면 (Adventure Map)**
   - 스크롤 가능한 맵 UI. 아래에서 위로 올라가는 형태(또는 좌우 스크롤).
   - 최상단 헤더 띠바에 `[⭐ 120]`, `[🔥 5일 연속]`, 그리고 **[🎯 오늘의 복습 미션 가기 (남은 카드 15장)]** 플로팅 버튼.
2. **레슨/복습 화면**
   - **새 레슨(Map 진입)**: 기존의 순차적인 앞/뒷면 학습. 마지막 장에서 '미션 클리어' 연출.
   - **복습(Today's Quest 진입)**: 카드를 뒤집었을 때 하단에 `[어려워요 🥵]`, `[알겠어요 😐]`, `[쉬워요 😎]` 세 가지 버튼이 나타나 간이 SRS 피드백 수집.
   - **음성 피드백 (TTS)**: 카드 앞면(단어)이 나타나거나 뒤집힐 때 Web Speech API를 통해 일본어 원어민 발음을 자동으로 읽어줌. 카드를 다시 듣고 싶을 때 누를 수 있는 스피커(🔊) 버튼 함께 제공.
3. **피드백 연출**
   - 미션 완료 시: 화면 가득 콘페티(종이 꽃가루)가 터지며 `+1 스탬프`, `+10 별` 획득 모달 표시.

## 5. 결론 및 기술적 의사결정 (Decisions)

- **SRS 피드백 자동화**: 만 7세 아동의 편의성을 위해 명시적인 피드백 버튼(어려워요/쉬워요)을 노출하지 않고, 퀴즈 모드의 정답/오답(시간 초과 포함) 결과를 바탕으로 백그라운드에서 SM-2 알고리즘 파라미터를 자동 갱신합니다.
- **저장소 전략**: 1단계로 `localStorage`를 사용하여 빠르게 MVP를 완성합니다. 이후 2단계에서 Firebase Auth + Firestore 기반의 클라우드 세이브(크로스 디바이스 동기화) 아키텍처로 확장 가능하도록 데이터 모듈(Adapter 패턴)을 준비합니다.
- **TTS (Text-to-Speech) 도입 전략**: 학습 경험 강화를 위해 Web Speech API (`ja-JP` 언어팩)를 채택합니다. iOS 등 모바일 브라우저의 정책(첫 터치 전 오디오 재생 차단)을 우회하기 위해, 카드를 넘기는 행위 자체를 사용자 인터랙션으로 간주하여 자연스럽게 음성을 자동 재생합니다.
- **이미지 리소스 효율화**: Phase 3 단어 확충 시, 이미지 에셋 수급으로 인한 지연을 막기 위해 1차적으로 플랫폼 내장 이모지(Emoji)를 활용하여 대규모 콘텐츠를 빠르게 구축하고 검증합니다.
